# リーグ戦順位表

3〜12チームの総当たりリーグ戦を作成し、試合結果から順位を自動計算するブラウザーツールです。

## 機能
- 3〜12チーム対応
- 1回総当たり、ホーム＆アウェイ方式
- 勝利・引分・敗戦の勝ち点設定
- 試合日程の自動生成
- 得点入力による順位表の自動更新
- 勝点、得失点差、得点、チーム名の順で順位決定
- 順位表コピー
- チーム一覧・リーグ戦データのブラウザー保存

## 公開
GitHubで `league-table` というPublicリポジトリを作成し、4ファイルをアップロードします。Settings → Pagesでmainブランチの `/ (root)` を公開します。
